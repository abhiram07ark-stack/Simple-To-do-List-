# Simple-To-do-List-
This is a simple To-Do List program in Python. Users can add, view, and remove tasks stored in a list. The program uses a loop to keep running until exit and if-elif-else statements to choose actions. It teaches lists, loops, indexing, and handling user input.

## Project Description
This project is a Simple To-Do List program built in Python. It allows users to add tasks, view all tasks, and remove tasks from a list. Tasks are stored in a Python list, and the program continuously runs in a while loop until the user chooses to exit. User actions are controlled using if-elif-else statements, and tasks are displayed with numbering using list indexes. The program uses len() to determine the number of tasks and input() to interact with the user.

## Common Mistakes
1. Comparing input with numbers instead of strings – input() always returns a string, so "1" should be used instead of 1.
2. Incorrect indentation – Python depends on proper indentation for loops and conditional statements.
3. Removing tasks without checking index – Trying to remove a task number that doesn’t exist can cause errors.
4. Not handling empty lists – Viewing or removing tasks from an empty list should be managed properly.
